# ADR-0002：源码根固定在 `src/`；同步资产进 `src/sync/`

- **状态**：已接受（修订）  
- **日期**：2026-11-10  
- **关联**：[`00-全局总任务纲领.md`](../00-全局总任务纲领.md) · [ADR-0001](./0001-tfm与上游同步.md)

## 背景

需确定 .NET 重写代码与上游只读资产在本仓库中的物理布局。

## 决策

1. **唯一源码根**：产品源码位于 **`src/`**。  
2. **无需改造资产** 统一放入 **`src/sync/`**，其下目录名与上游 **1:1**（如 `src/sync/frontend`）。  
3. **C# 重写** 放在 `src/cmd`、`src/internal`、`src/cli`、`src/client`，路径对齐上游同名目录（**不**放进 `sync/`）。  
4. **部署类**（`docker` / `deploy` / `helm`）留在 `src/` 适配区，不作为只读全量同步默认项。  
5. 仓库根仅保留 `README.md`、`doc/`、版本控制元数据等。  
6. 同步脚本只写入 `src/sync/`，禁止覆盖重写区。

## 后果

**正面**：同步区与重写区物理隔离，避免 robocopy 误伤 C#；对照上游仍用同名相对路径（前缀 `sync/`）。  
**代价**：引用前端/解析路径时须带 `src/sync/` 前缀。
